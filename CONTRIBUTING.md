# المساهمة · Contributing

[العربية](README.md) · [English](README_EN.md) · [Development guide](docs/DEVELOPMENT.md)

## بالعربية

يمكنك المساهمة بتصحيح الشرح أو الترجمة، أو الإبلاغ عن خلل، أو اقتراح تحسين للعرض والتحكم. افتح [بلاغًا](https://github.com/adel2184/mosque-tv/issues/new) يوضح الفكرة، أو أرسل طلب سحب بتعديل محدد وشرح أثره.

عند الإبلاغ عن مشكلة، اذكر:

- إصدار التطبيق، وطراز التلفاز، وإصدار Android أو اسم المتصفح وإصداره.
- خطوات إعادة المشكلة، وما توقعت حدوثه، وما ظهر فعليًا.
- لغة الواجهة وما إذا كان الجهاز متصلًا بالإنترنت، عندما يتعلق ذلك بالمشكلة.
- صورة أو سجل مختصر بعد إزالة المعلومات الخاصة.

احذف من المواد المنشورة مفاتيح التوقيع وكلمات المرور والعناوين الخاصة وبيانات التواصل وحملات التبرع ورموز اقتران الهاتف. استخدم بيانات تجريبية في الصور. لا يلزم نشر ملف إعدادات الجامع كاملًا لتوضيح خلل.

في تعديلات التوثيق، تحقّق من الروابط والمسارات وتوافق الشرح العربي والإنجليزي مع السلوك الفعلي. في تعديلات الشيفرة، عدّل المصدر تحت `dev/` عند الحاجة، وأعد البناء، ثم شغّل الفحوص المناسبة الموضحة في [دليل التطوير](docs/DEVELOPMENT.md). اذكر ما اختبرته والجهاز المستخدم وحدود التجربة؛ معاينة المتصفح لا تثبت نجاح الوظائف الأصلية على التلفاز.

احتفظ بإشعارات مصادر البيانات والمكونات وتراخيصها. لا تغيّر نصًا دينيًا أو بيانات مواقيت دون مصدر واضح ومراجعة مناسبة.

## English

Contributions can improve documentation, translations, display behavior or remote control. Open an [issue](https://github.com/adel2184/mosque-tv/issues/new) with a concrete proposal, or submit a focused pull request explaining the resulting behavior.

For a bug report, include:

- App version, TV model and Android version, or browser name and version.
- Steps to reproduce, expected behavior and actual behavior.
- Interface language and connection state when relevant.
- A short, sanitized screenshot or log if it helps explain the problem.

Remove signing keys, passwords, private addresses, contact details, donation campaign information and phone-pairing QR codes before posting. Use demonstration data in screenshots. A complete mosque settings export is usually unnecessary.

For documentation changes, check links, paths and consistency between Arabic and English instructions. For code changes, edit the appropriate source under `dev/`, rebuild and run the relevant checks in the [development guide](docs/DEVELOPMENT.md). State what you tested, on which device, and any limits; a browser preview does not verify native TV features.

Preserve data attribution and component license notices. Changes to religious text or prayer data need a clear source and appropriate review.
