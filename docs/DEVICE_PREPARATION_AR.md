# تهيئة التلفاز والتحسينات الاختيارية

يصف هذا الدليل واجهة التهيئة الجديدة في مصدر المشروع. نتائج بناء APK وتجارب الطرز تُسجل في تقرير التحقق بعد إجرائها؛ نجاح اختبارات القواعد المحلية لا يثبت عمل كل خيار على كل تلفاز.

افتح مركز التحكم ← **تهيئة التلفاز / TV preparation**. تتبع الواجهة لغة التطبيق، العربية أو الإنجليزية. لا يغيّر فتحها أو تبديل أقسامها أو تحديث حالتها أي إعداد في الجهاز. الأسهم للتنقل، وOK للاختيار، ورجوع للإغلاق. أثناء تنفيذ تغيير تنتظر الواجهة اكتمال التنفيذ والتحقق قبل السماح بالخروج؛ دخول وضع الصلاة يغلقها ويحتفظ بسجل الاستعادة.

تعرض الواجهة حالة الاتصال المحلي، وأربعة أقسام: **التطبيقات / Apps**، و**الحركة / Animations**، و**التخزين / Storage**، و**الاستعادة / Restore**. تظهر الأخطاء بعلامة `!!`؛ لا تعتبر الخطأ أو انقطاع التأكيد نجاحًا.

## الاتصال والمراجعة

القراءة وعرض الخطة محليان. التنفيذ المباشر يحتاج جلسة ADB محلية يتيحها التلفاز ويفوضها المشغّل؛ لا يحتاج إنترنت. زر **اتصال محلي / Connect locally** يبدأ هذه الخطوة صراحةً. بعض الأنظمة لا تتيحها، وفي هذه الحالة يبقى فتح **إعدادات التطبيق / App settings** للمراجعة اليدوية متاحًا. فتح إعدادات النظام لا يعني أن تغييرًا نُفذ.

يحدث التنفيذ على عامل متسلسل. تُحفظ الحالة الأصلية قبل إرسال تغيير، وتُقرأ النتيجة من الجهاز قبل تأكيد النجاح. قد تتوقف خطة متعددة العناصر بعد تغيير بعضها؛ راجع الحالة والسجل بدل افتراض تطبيق الخطة كلها. عند تعذر تأكيد عنصر تبقى معلومات استعادته محفوظة للمراجعة وإعادة المحاولة.

## التطبيقات

ابدأ من قائمة غير محددة، واختر التطبيقات التي لا تحتاجها فقط، ثم **مراجعة المحدد / Review selected**. تظهر الأسماء والعدد قبل تأكيد التعطيل. التعطيل يحفظ بيانات التطبيق؛ ليس حذفًا له.

القائمة الحالية مقترحات محددة تُفحص مقابل التطبيقات المثبتة وخدماتها. تُحمى واجهة HOME والشبكة والريموت والإدخال وWebView ومكونات النظام الضرورية، وتُحجب المقترحات الخاصة بـTCL عن مصنّع آخر. يضيف الفهرس المجتمعي المرفق اقتراحات عند مطابقة الموديل والمصنّع وإصدار Android؛ تُرفض المطابقة المبهمة أو غير المكتملة. وجود سجل لطراز لا يعني اختبار جميع تطبيقاته ميدانيًا، وأسماء الطرز والبلاغات المجتمعية ليست اعتمادًا عامًا للتوافق.

يظهر **استعادة هذا التطبيق / Restore this app** للعناصر المسجلة فقط. يعيد الحالة الأصلية المسجلة لذلك العنصر ويتحقق منها. التطبيقات التي كانت معطّلة قبل استخدام الأداة لا تُفعّل ضمن هذه الخطة.

## حركة واجهات النظام

زر **ضبط الحركة على 0.5× / Set animations to 0.5×** اختياري وله تأكيد مستقل. يشمل إعدادات انتقال النوافذ والانتقال بين الصفحات ومدة الحركة المدعومة. يقلل مدة الانتقالات؛ لا يمثل زيادة مضمونة في سرعة المعالج أو الذاكرة.

تُسجل القيم الأصلية كما وردت، بما فيها غياب قيمة أصلًا، قبل الكتابة. تُقرأ القيم بعد التطبيق، ويظهر التعذر بدل إعلان نجاح غير مؤكد. يعرض الملخص الأصول المسجلة للاستعادة؛ ليس فحصًا تلقائيًا متجددًا لإعدادات النظام عند فتح الصفحة.

**استعادة الحركة الأصلية / Restore original animations** يعيد كل قيمة مسجلة إلى أصلها، ولا يفترض أن الأصل هو `1` أو يختار قيمة موحدة للجميع. السجل التالف يمنع التغيير والاستعادة الآلية حتى مراجعته.

## التخزين والملفات المؤقتة

يظهر مقدار التخزين المتاح وحالة انخفاض المساحة. لا يتاح **إخلاء مساحة مؤقتة / Free cached space** إلا عند تحقق شرط انخفاض المساحة الفعلي، ثم يحتاج تأكيدًا صريحًا. إذا كانت المساحة كافية فلا يبدأ تنظيف لمجرد فتح الصفحة.

يُحجب التنظيف أيضًا عند وجود ملف محفوظ في ذاكرة التحديث المخصصة. أكمل تثبيته أو ألغِ مهمة التحديث من قسمها قبل إعادة طلب التنظيف؛ لا تحذف ملف التحديث يدويًا لتجاوز الحماية.

ترسل الأداة طلبًا إلى Android لإخلاء المؤقت القابل للإزالة، ثم تقرأ المساحة مجددًا. تعرض النتيجة قبل الطلب وبعده؛ قبول الطلب لا يضمن تحرير حجم معين، وقد تعود ملفات المؤقت لاحقًا. العملية لا تمثل مسح بيانات الجامع أو إعادة ضبط المصنع.

**إزالة الملفات المؤقتة غير قابلة للاستعادة.** لذلك تبقى منفصلة عن سجل التغييرات القابلة للتراجع، ولا يعيدها زر الاستعادة الشاملة.

## استعادة تغييرات الأداة

يعرض قسم الاستعادة عدد التطبيقات وإعدادات الحركة المسجلة. **استعادة كل تغييرات هذه الأداة / Restore all of this tool’s changes** يعيد ما تسجله هذه الأداة فقط إلى حالته الأصلية، مع قراءة النتيجة. يمكن أيضًا استعادة تطبيق واحد أو إعدادات الحركة وحدها.

هذا ليس ضبط مصنع أو إعادة جميع إعدادات التلفاز إلى الافتراضيات. لا يشمل اختيار HOME أو تعطيل مشغّل سبق أن ضبطه المستخدم خارج هذه الأداة، ولا يغيّر بيانات الجامع والمواقيت. تبقى المدخلات التي تعذر تأكيد استعادتها في السجل؛ لا تُحذف لمجرد بدء الطلب.

## الإبلاغ والمشاركة الاختيارية

يفتح **الإبلاغ عن مشكلة / Report a problem** واجهة مستقلة. اكتب وصفًا موجزًا، وراجع معاينة JSON، ثم أرسل بعد التأكيد إذا رغبت. المعاينة محلية، والإرسال يحتاج إنترنت. [الخدمة العامة](https://mosque-tv-reports-adel2184.netlify.app) تخص حساب مالك المشروع؛ يقرأ المالك التقارير من **Data & Storage → Blobs** في Netlify دون قائمة تقارير عامة. لا يُرسل تقرير تلقائي عند فتح التهيئة أو فشل عملية، ولا يُنشأ طابور إرسال دون اتصال.

تتوفر للمشغّل على الكمبيوتر أداتنا الأصلية `optimize/share.cjs` وغلافها `optimize/share.sh`، مع Node 20 أو أحدث. مثال معاينة لا يرسل شيئًا:

```text
node optimize/share.cjs --preview --problem --owner "وصف موجز للمشكلة" --out reviewed-report.json
```

راجع الملف المنقح أولًا. عند اختيار الإرسال صراحةً:

```text
node optimize/share.cjs --send reviewed-report.json --confirm
```

تنفذ الأداة إرسال الملف المعروض نفسه، ولا تجمع جردًا من التلفاز. التنقيح التقريبي لا يغني عن مراجعة النص وحذف المعلومات الخاصة. راجع [دليل خدمة التقارير](../services/reports/README.md) لمعرفة المخطط والاحتفاظ بالبيانات وحدود الخدمة.

ملفات UrTV المسماة `optimize.sh` و`reset.sh` و`keep.sh` تخص مشروعه؛ تستخدم هذه النسخة أزرار التهيئة الأصلية الموضحة أعلاه. ملفا المشاركة `share.cjs` و`share.sh` هنا من تنفيذ مشروع شاشة الجامع، وليسا نقلًا لأوامر تحسين أو تقارير UrTV.
