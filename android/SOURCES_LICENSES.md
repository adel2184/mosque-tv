# مكونات ومصادر نسخة التلفاز

واجهة الجامع ووحدات Android كُتبت للمشروع. دُرس تصميم UrTV ولم تُنقل إضافاته غير واضحة الترخيص. لا يُضم LaunchAPP أو UrTV داخل APK.

مركز التحكم ومحرك قياس السرعة كود أصلي للمشروع. لا تُضم مكتبة Cloudflare أو شيفرة UrTV. استُخدم [توثيق Cloudflare الرسمي](https://github.com/cloudflare/speedtest) و[اختبارات عنوان التنزيل](https://github.com/cloudflare/speedtest/blob/564a2c113a0e2c014dc6377c13375524c252c3ee/tests/unit/engines/urlConstruction.test.ts) للتحقق من نقطة HTTPS العامة `speed.cloudflare.com/__down` ومعامل bytes. القياس طلب تنزيل محدود 5 ميجابايت، بلا رفع أو تسجيل نتائج إضافي من التطبيق؛ يحتاج إنترنت ويبدأ باختيار المستخدم فقط.

- Project Nayuki QR Code generator Java 1.8.0، ترخيص MIT. أربع ملفات أصلية في android/vendor/qrcodegen مع إشعاراتها. licenses/qrcodegen-MIT.txt داخل APK. المصدر: https://github.com/nayuki/QR-Code-generator/tree/v1.8.0/java/src/main/java/io/nayuki/qrcodegen . للاقتـران المحلي فقط، ولا يستبدل صورة التبرع.
- Noto Sans Arabic، ترخيص SIL OFL، إشعاره ومصدره داخل assets/fonts ومضمّنان.
- Adhan JS 4.4.6 بترخيص MIT: محرك الحساب المحلي مرفق داخل التطبيق ويعمل دون شبكة بعد طلب المستخدم. الإعدادات الخمس تحمل أسماء أم القرى والرابطة والمصرية وأمريكا الشمالية وكراتشي؛ هذه إعدادات حساب لا اعتماد صادر عن الجهات. تُرفض الأحداث غير المحلولة أو غير المنتهية أو المتداخلة بدل اختلاق أوقات.
- HijriDate 2.6.0 بترخيص MIT: نُقلت بدايات أم القرى المدنية إلى جدول محلي كامل من 1924-08-01 إلى 2077-11-16، مع بداية تالية للحماية. تحفظ المدد التاريخية كما وردت في المصدر. لا يحتاج التحويل إلى تنزيل، ولا يمثل إعلان رؤية الهلال المحلي. تبقى بيانات التقويم القديم المنفصلة محفوظة للمراجعة.
- GeoNames cities15000 وcountryInfo وأسماء بديلة موسومة، بلقطة 23 نوفمبر 2026: 244 بلدًا وإقليمًا و 34,247 مدينة. تتوفر 1,038 تسمية مدينة عربية؛ يستخدم الباقي اسم المصدر ASCII أو الاسم الرئيسي. الترخيص CC BY 4.0، والإسناد في licenses/geonames-NOTICE.txt. أسماء البلدان عبر Intl.DisplayNames لها إشعارات Unicode في licenses/Unicode-3.0.txt وlicenses/location-display-names-NOTICE.txt. ليس الدليل حصرًا لكل القرى أو ضمانًا لصحة الإحداثيات.
- صورة التبرع والنصوص قدمها المستخدم؛ الصورة ببايتاتها الأصلية. لا ادعاء باعتماد جهة أو اختبار مسح من بعيد.
- يضم فهرس CleanYourTV عدد 508 سجلات طرازات، منها 92 سجلًا جديدًا للتعرّف على الطراز فقط. قورنت 1017 وثيقة مصدر في النسخة الجديدة مع 833 وثيقة في النسخة السابقة. احتفظ التطبيق باقتراحات الحزم المشتركة للطراز نفسه وإصدار Android نفسه، واستبعد من الاقتراحات العامة كل حزمة سحبها المصدر من أحد الطرز التي راجعناها. تخضع الاقتراحات لفحص مكونات النظام على الجهاز ولموافقة المشغّل. رخصة البيانات MIT، وحقوق النشر © 2026 Gathin. يحتوي APK الرخصة في `licenses/CleanYourTV-MIT.txt` وبيان الاشتقاق في `licenses/CleanYourTV-NOTICE.txt`. [المصدر المثبت](https://github.com/Gathin23/cleanyourtv/tree/fe6cdcefa817da9f6facd3a17a3c5a086124f258) و[نسخة المقارنة](https://github.com/Gathin23/cleanyourtv/tree/3cd274f866b71ec15e4f7d8c796514b0baa8033c).

اختير [UmmahAPI](https://ummahapi.com/api/docs) مصدرًا اختياريًا صريحًا للمواقيت المحسوبة عند الاتصال. جُربت استجابات يومية وشهرية حقيقية في جولة التطوير؛ لا تعني هذه التجربة نجاح تنزيل 26 استجابة كاملة على التلفاز. الجلب يطلب 24 شهرًا ويومي الحدود، مع فحص المصدر والمكان والمنطقة والتوقيت والمدى قبل الحفظ. لا تُضم شيفرة خادم المزود أو مكتبة له، ولا تدعي الحزمة أن بياناته صادرة عن جهة رسمية. يبقى الحساب المحلي والاستيراد من ملف متاحين دون شبكة. تفاصيل الإسناد والمعاملات والتغطية في [مصادر المكان](../docs/LOCATION_SOURCES_AR.md) و[مصادر البيانات](../DATA_SOURCES.md).

خدمة التقارير وواجهتها العربية/الإنجليزية والمنقح المشترك و`optimize/share.cjs` و`share.sh` من تنفيذ المشروع الأصلي. ملفات المعاينة العامة نفسها مرفقة في APK، وتعمل دون إنترنت ولا تتصل إلا بإجراء الإرسال المؤكد عبر الوحدة الأصلية. خادم المالك المنفصل يستخدم `@netlify/blobs` 11.1.10 بترخيص MIT وإقفال اعتماداته في `services/reports/package-lock.json`؛ SDK الخادم وNetlify CLI ليسا داخل APK. تحفظ الخدمة النص المنقح الذي راجعه المستخدم ولا ترسل إلى UrTV أو Google Forms أو GitHub Issues، ولا توفر قراءة عامة للتقارير. لا يدعي التنقيح إخفاء الهوية؛ قد يعالج المضيف IP للاتصال وحد الطلبات، ولا يحفظه كود الخدمة ضمن التقرير. [المخطط والاحتفاظ وحدود الخدمة](../services/reports/README.md).

تستخدم عملية البناء JDK 17 ومنصة Android SDK 37.2 وأدوات البناء 37.0.0 وNode. يحتفظ التطبيق بالحد الأدنى API 24 ويستهدف API 35. يتطلب الانتقال إلى الهدف 37 التحقق من إذن الشبكة المحلية والتعامل مع منحه أو رفضه أثناء الاقتران. تبقى أدوات التطوير ومفتاح التوقيع خارج الحزمة. [قواعد Android للشبكة المحلية](https://developer.android.com/privacy-and-security/local-network-permission)

العرض يحافظ على الأصل https://appassets.androidplatform.net/assets/index.html والتخزين السابق. أذونات الحزمة INTERNET وACCESS_NETWORK_STATE وREQUEST_INSTALL_PACKAGES لوظائف التحديث والاقتران والتهيئة وقياس السرعة وجلب المواقيت الصريح. يبقى طلب الموارد الخارجية في WebView مرفوضًا؛ الجلب الاختياري يتم في الوحدة الأصلية إلى نقاط المزود المحددة. لا إذن تخزين عام أو إدارة جهاز أو خدمة وصول أو تراكب أو مستقبل إقلاع جديد.

نجاح التوقيع والبناء لا يثبت تشغيل كل وظائف TCL. تقارير الفحص تميز المعاينة ومحاكاة DOM عن اختبار التلفاز. قرارات HOME والتثبيت وتفويض التهيئة مستقلة عن JSON الجامع.
